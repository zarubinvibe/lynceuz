# Лестница разведки источника

## Суть

**Отказ - это последняя ступень, а не первая.** Если у источника не работает очевидный путь,
инструмент обязан пройти лестницу альтернатив и вернуть отказ только тогда, когда красными
оказались все ступени. Каждая пройденная ступень записывается в отчет: что пробовали, что ответил
сервер, почему не подошло. Пустой отказ без перечня проб - дефект, а не честность.

## Лестница

1. **Прямой запрос страницы.** Отдает ли сервер готовый ответ без JS. Проверяется по коду ответа
   и по наличию содержательной части, а не по факту "200 OK": форма поиска с пустой выдачей - это
   не результат.
2. **Признаки клиентского рендеринга.** `<noscript>`, вызовы вида `getDocList()`, `__NEXT_DATA__`,
   пустые контейнеры под списки. Если найдены - обычный запрос бесполезен, идем дальше.
3. **`robots.txt` целиком, а не только Disallow.** Директива `Sitemap:` - это приглашение
   краулеру от самого сайта. `Clean-param` показывает, какие параметры сайт считает штатными для
   обхода, то есть какие пути он ожидает видеть у роботов.
4. **Карта сайта.** Часто отдает десятки тысяч адресов документов, минуя поиск. Формат бывает
   `.xml.gz`, при этом `fetch` может распаковать сам - разбор обязан переживать оба случая.
5. **Страницы документов напрямую.** Даже когда выдача рисуется JS, сами документы обычно
   отдаются сервером. Проверяется наличием содержательных маркеров в тексте.
6. **Иные открытые входы.** RSS, `.well-known`, API, экспортные и печатные версии, зеркала,
   разделы каталога, страницы по судье, участнику, статье закона.
7. **Браузерный режим.** Когда собственный поиск сайта доступен только человеку. Это законный
   путь пользователя, а не обход.
8. **Честный отказ** с перечнем пройденных ступеней и точной причиной по каждой.

## Красные линии

Лестница расширяет способы, но не права:

- **`Disallow` не обходится ничем.** Если AJAX-эндпоинт выдачи закрыт в robots, его не дергают ни
  напрямую, ни через браузер как подресурс. Закрыто - значит закрыто.
- **Чужая поисковая выдача не скрапится.** Google, Bing и подобные - вне игры, независимо от того,
  насколько это ускорило бы работу.
- **Ничего платного и никаких новых зависимостей** без явного разрешения владельца.
- **Вежливость обязательна:** ограниченная параллельность, лимит страниц, уважение к нагрузке.

## Замер, которым правило подтверждено

СудАкт, 31.08.2026:

| Ступень | Результат |
|---|---|
| Прямой запрос поиска | 200 OK, но выдачи нет - только форма |
| Признаки JS | `<noscript>Необходим JavaScript</noscript>`, `getDocList()` |
| AJAX-эндпоинт | `/regular/doc_ajax/` закрыт в robots - НЕ трогаем |
| robots целиком | найдена директива `Sitemap:` |
| Карта сайта | **97 164** документа: 19 220 общей юрисдикции, 16 103 мировых, 14 179 арбитражных, 498 ВС |
| Страницы документов | рендерятся сервером, ~19,5 КБ живого текста |
| Итог | тематический сбор пошел БЕЗ браузера и в рамках robots |

Ограничение, найденное тем же замером: 800 арбитражных документов из карты дали 1 тематическую
находку (дело А70-1962/2025). Карта хороша для сплошного и свежего сбора, но для узкой темы
перебор дорог - там нужен собственный поиск сайта, то есть ступень 7.
