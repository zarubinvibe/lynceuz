# Lynceuz - проектная конституция

> Только правила этого проекта. Глобальные правила наследуются. Файл держать короче 200 строк.

## Что за проект

Lynceuz - локальный CLI-роутер для бесплатного сбора публичных веб-данных. Он сам выбирает доступный движок, бесшовно переключается при отказе и всегда сохраняет источник, хэш, время и путь к артефакту.

## Стек и команды

- Стек: Node.js 20+ (ядро и CLI), Python 3.11+ только для опциональных Crawl4AI/Playwright-адаптеров.
- Установка: `npm install` (в v1 внешних Node-зависимостей нет).
- Запуск: `node src/lynceuz.mjs health`.
- Тесты: `npm test`.
- Линт/типы: `npm run check`.

## Инварианты

- Денежный бюджет по умолчанию и в v1: `0`. Платный fallback запрещён.
- Порядок local-first. Облачные free credits выключены без явного флага.
- Сеть public-only: блокировать localhost, private/link-local/metadata IP, опасные схемы и каждый redirect.
- `robots.txt`, лимиты времени/размера/страниц, retry и cache обязательны.
- Никаких login, paywall/CAPTCHA bypass, paid proxy или CAPTCHA solver.
- Данные не выдумывать. У каждого результата есть URL, дата, SHA-256 и журнал попыток.
- Внешние CLI запускать только через argv без shell.
- Сырой контент и cache лежат в `.lynceuz/`, никогда в git.

## Архитектура

- `src/lynceuz.mjs` - CLI, policy, router, cache и manifests.
- `src/lynceuz-helper.py` - локальный parser/browser bridge, без LLM и платной сети.
- `evals/` - детерминированные hostile tests; живой интернет не нужен для основного гейта.
- `specs/` - цель, требования и исходная справка; `docs/` - использование и контракты.

## Правила проекта

- Ponytail: stdlib и уже установленные движки раньше новых зависимостей.
- Сначала specs, затем код, затем evals и свежий полный прогон.
- Новое сетевое поведение без hostile-теста не принимать.
- Секреты только в env/secret manager, никогда в argv, manifest, cache, логах и git.
- Перед API-кодом сверять актуальный синтаксис с Context7/официальной документацией.
